Apache ShenYu 2.7.0 Released！Apache ShenYu 2.7.0 发布！

刘宏宇2025/2/13大约 7 分钟

关于Apache ShenYu  关于 Apache ShenYu

Apache ShenYu 一款使用 Java Reactor 开发的响应式API 网关。以其高性能，动态灵活的流量管控，热插拔，易部署等特性，开箱即用为用户提供整套全生命周期的 API网关，包含 API注册、服务代理、协议转换、API文档与 API治理等功能。

官网: https://shenyu.apache.org
官网： https://shenyu.apache.org

GitHub: https://github.com/apache/shenyu
